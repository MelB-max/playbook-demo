# Product playbook (demo)

**Live demo:** https://melb-max.github.io/playbook-demo/

An interactive product playbook for new sales joiners: follow one persona through the story, the program and the call. This demo uses a made-up academy and program; every name, number and link is fictional.

## What to look at
- A persona diary, then "why now" stats and a spreadsheet-vs-data-science toggle.
- A skills wheel, a clickable map of who you'll talk to, and a flip-card glossary.
- A phase roadmap, filterable project cards, mentors and learner voices.
- A step-through call for pre-sales and full-sales, probing questions, objection cards, "what to send" and a self-check quiz.
- Light and dark mode, keyboard friendly, one self-contained HTML file.

## Built with
One shared HTML shell plus a content file per program (pages + a data object), built into a single static page.
